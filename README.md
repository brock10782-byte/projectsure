# 💖 100% Customizable Love Website - Reunion Edition

A romantic, customizable interactive love website created for celebrating relationship milestones and anniversaries.

## ✨ Features
- 🌸 **Floating Ambient Particles**: Rose petals and glowing hearts drifting gracefully across the screen.
- 🎵 **Web Audio Synthesizer**: Built-in royalty-free romantic background melody using the Web Audio API (no external audio files required).
- 🎁 **3 Interactive Gifts Hub**:
  1. *Midnight Love Text Mockup*
  2. *Redeemable Love Coupons* (Romantic Dinner, Movie Night, Big Warm Hug, Sweet Surprise)
  3. *Official Certificate of Endless Love*
- ⚙️ **In-Browser Personalizer Drawer**: Easily change names, anniversary dates, secret passcodes, and love letters in real time without touching code.
- 📱 **Fully Responsive**: Beautifully tailored for desktop, tablet, and mobile browsers.

---

## 🚀 How to Run Locally

### Option 1 (Recommended):
Double-click [`run.bat`](run.bat) to launch the local web server at [http://localhost:8089](http://localhost:8089).

### Option 2:
Double-click [`open_direct.bat`](open_direct.bat) or open [`index.html`](index.html) directly in any modern browser.

## 📤 How to Upload to GitHub

Open terminal / command prompt in this directory and run:

```bash
# 1. Initialize git
git init

# 2. Add all files
git add .

# 3. Create initial commit
git commit -m "Initial commit: Romantic Love Website"

# 4. Set main branch
git branch -M main

# 5. Connect to your GitHub repository (replace with your repo URL)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

# 6. Push to GitHub
git push -u origin main
```
